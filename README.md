# MIND LAB

혼자 힘든 시간을 보내는 사람이 도움으로 이어지도록 돕는 무료 웹앱입니다. 가입과 설치 없이 링크로 바로 열리고, 기록은 사용자의 기기에만 저장됩니다. 진단이나 치료를 대신하지 않습니다.

## 바로 여는 링크

주소 뒤에 `#화면이름`을 붙이면 그 화면부터 열립니다. 위기 안내를 공유할 때는 `#calm`을 쓰세요.

- `#calm` 지금 힘들어요
- `#help` 도움받는 법
- `#safety` 내 안전 계획
- `#reach` 말 꺼내는 법
- `#allies` 곁에 있는 사람에게

## 내용을 고칠 때

- 안내 문구와 연락처는 `guide.js`, 앱 동작은 `app.js`에 있습니다.
- 의학 내용이나 연락처를 바꾸면 출처를 확인하고 `guide.js`의 `REVIEWED_ON`을 고칩니다.
- 파일을 고쳐 배포할 때는 `sw.js`의 `CACHE` 번호를 올립니다.
- 심리상담 바우처 안내는 2026년 기준입니다. 해가 바뀌면 다시 확인하세요.

## 홈 화면에 추가 (선택)

인터넷 주소가 `https://`로 열려야 합니다.

- **Android:** Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**
- **iPhone:** Safari 공유 버튼에서 **홈 화면에 추가**

오프라인으로 사용할 수 있는 범위는 휴대폰과 브라우저에 따라 달라질 수 있습니다.
