# MIND LAB 휴대폰 앱 설치 안내

MIND LAB은 별도의 앱스토어 프로그램 대신, 웹사이트를 휴대폰 홈 화면에 앱처럼 추가하는 **PWA** 방식으로 준비하고 있습니다. 앱스토어에 올리는 설치 파일은 아닙니다.

## 설치 전에 필요한 것

MIND LAB을 인터넷 주소로 공개하고, 그 주소가 보안 연결(`https://`)로 열려야 합니다. 처음 한 번은 인터넷에 연결된 상태로 사이트를 방문해야 합니다.

## Android 휴대폰

1. Chrome에서 MIND LAB 웹사이트를 엽니다.
2. 오른쪽 위 메뉴(점 세 개)를 누릅니다.
3. **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.

## iPhone

1. Safari에서 MIND LAB 웹사이트를 엽니다.
2. 공유 버튼을 누릅니다.
3. **홈 화면에 추가**를 선택합니다. 표시되면 **웹 앱으로 열기**를 켭니다.

오프라인으로 사용할 수 있는 범위는 휴대폰과 브라우저에 따라 달라질 수 있습니다.
